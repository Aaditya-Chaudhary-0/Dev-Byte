## Current product scope
Authentication; Student Profile; Mentor Profile; Skills; Projects/Portfolio; Teams; Hackathon Finder; AI Team Matcher; Skill Swap; Battle Arena; Contests; Mentor Sessions; Assignments; XP; Reputation; Badges; Leaderboard; AI Mentor; Student Dashboard; Mentor Dashboard.

## Project principles
- Prioritize complete, working user journeys over isolated feature depth.
- Keep the architecture modular and maintainable.
- Use deterministic business logic for authoritative decisions and AI for advisory/explanatory tasks where documented.
- Preserve source attribution for aggregated external opportunities.
- Keep sensitive operations enforced by the backend.

## Out of scope
The following items are not part of the current product definition: mentor verification; recruiter/college panels; notifications/alerts; full real-time messaging; AI Career Assistant; AI Hackathon Matcher; AI Code Review; 1v1/team real-time battles; automatic Google Meet creation; real production payouts; advanced multi-agent infrastructure; advanced semantic matching beyond the documented AI Team Matcher; GitHub automatic synchronization.

This document defines the current project scope. It does not define separate product releases.
